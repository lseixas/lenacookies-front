# docs/

Documentação operacional do **Lena Cookies Front**. Fonte de verdade para agentes e humanos sobre contexto, specs, infra, planos, acesso a ferramentas e histórico de tasks.

## Pastas

| Pasta | Conteúdo |
|-------|----------|
| [tasks/](./tasks/) | Registro de ações e prompts (versionamento operacional) |
| [context/](./context/) | Overview do projeto e guias para agentes |
| [infra/](./infra/) | Ambientes e serviços em execução |
| [plans/](./plans/) | Ideias e planos futuros |
| [specs/](./specs/) | Specs de produto e áreas |
| [access/](./access/) | Como autenticar/usar ferramentas (sem secrets) |

## Regras curtas para agentes

- **Boot:** ler `AGENTS.md` → `context/` → `access/` se cloud → consultar specs/infra/plans/tasks.
- **Antes:** não contradizer decisões documentadas sem registrar a mudança.
- **Ao finalizar:** criar task a partir do template, atualizar índice, sync docs tocados.
- **Ideias:** registrar em `plans/ideas.md` (topo); planos formais com arquivo datado.
- **Em dúvida:** perguntar — nunca assumir.
