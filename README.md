# Doce Mordida

Site de vitrine para a **Doce Mordida** — cookies artesanais.  
Projeto de portfolio: uma página para mostrar sabores, embalagens e como encomendar. **Sem checkout nem pagamentos.**

**Demo ao vivo:** [lseixas.github.io/lenacookies-front](https://lseixas.github.io/lenacookies-front/)

## O que é

Landing page exibicionista do negócio da minha prima: cardápio com preços, fotos reais dos cookies e das sacolas/caixas kraft, e contato direto por Instagram e WhatsApp.

## Destaques

- Hero com a marca
- Cardápio (Tradicionais, Gourmet, Recheados, Fitness)
- Slideshows dos exemplares e das embalagens (autoplay + controle manual)
- Seção de encomendas com mascote pixel
- Layout responsivo

## Stack

React 19 · TypeScript · Vite 8 · CSS próprio

## Como rodar

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

> Em produção o site usa base `/lenacookies-front/` (GitHub Pages). O `npm run dev` já respeita essa base.

## Portfolio / GitHub Pages

Este repositório publica o site sozinho a cada push em `main` (Actions → GitHub Pages).

URL: `https://lseixas.github.io/lenacookies-front/`

No GitHub: **Settings → Pages → Source: GitHub Actions**.
